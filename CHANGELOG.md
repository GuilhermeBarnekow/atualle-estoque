# Changelog

Todas as mudanças notáveis serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2024-05-02

### Adicionado
- Login com controle de acesso (admin/operator)
- Cadastro completo de produtos com fotos
- Gerenciamento de categorias
- Movimentações de estoque (entrada/saída/ajuste)
- Relatórios em PDF
- Interface responsiva em JavaFX
- Alertas de baixo estoque
- Busca em todas as telas
- Validações de dados
- Logs de operações
- Banco SQLite com índices otimizados

### Melhorias UI
- Tema moderno com cores consistentes
- Feedback visual para ações
- Atalhos de teclado
- Tooltips informativos
- Tabelas com ordenação
- Formulários organizados
- Mensagens de erro claras

### Técnico
- Arquitetura MVC
- DAO pattern para acesso a dados
- Testes unitários (85% cobertura)
- Documentação JavaDoc
- Build com Maven
- CI/CD com GitHub Actions

## [0.9.0] - 2024-04-15

### Adicionado
- Primeira versão beta
- Funcionalidades core implementadas
- Testes iniciais

### Corrigido
- Problemas de performance em listagens
- Validações de formulários
- Cálculos de estoque

## [0.5.0] - 2024-03-01

### Adicionado
- Protótipo inicial
- Estrutura básica do projeto
- Configuração do ambiente
